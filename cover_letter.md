### Motivation and Timeliness
The artificial intelligence paradigm is undergoing a critical transition from passive, sequence-to-sequence foundation models toward autonomous **Agentic AI systems**. These architectures integrate Large Language Models (LLMs) with multi-horizon planning engines, persistent memory, heterogeneous tool execution interfaces (APIs, OS shells, database connections), and multi-agent coordination frameworks. While enabling unprecedented automation, this paradigm dismantles classical security perimeters by collapsing the distinction between untrusted data and executable control logic. As industry rapidly adopts standards such as the Model Context Protocol (MCP) and OS-level Computer-Use interfaces, systematic analysis of the emerging attack surface has become an urgent open challenge for computer science and cybersecurity.

### Key Contributions of this Survey
This manuscript provides a comprehensive, rigorous systematization of the agentic security landscape:
1. **End-to-End Reference Architecture & Expanded TCB:** We formalize the four-phase *Perception–Cognition–Action–Reflection* lifecycle and critically map the expanded Trusted Computing Base (TCB), delineating fragile trust boundaries across single-agent, hierarchical, and decentralized swarms.
2. **Unified Threat Model & Multi-Layer Taxonomy:** We systematically classify attacks spanning prompt-level manipulations, Retrieval-Augmented Generation (RAG) and embedding space poisoning, memory corruption, tool shadowing, Remote Code Execution (RCE), Model Context Protocol (MCP) host-client-server vulnerabilities, and Byzantine consensus subversion in Multi-Agent Systems (MAS).
3. **Comparative Evaluation of Defense-in-Depth:** We critically examine defensive paradigms, contrasting heuristic guardrails with formal policy verification, capability-based sandboxing, and runtime invariant enforcement.
4. **Benchmarking & Governance Synthesis:** We provide an exhaustive comparative matrix of empirical benchmarks, evaluate compliance with emerging governance mandates (e.g., OWASP Top 10 for Agentic AI, MITRE ATLAS, EU AI Act), and outline an actionable research agenda for secure, verifiable autonomy.
