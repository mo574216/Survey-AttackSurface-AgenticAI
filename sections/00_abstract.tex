\begin{abstract}
The integration of Large Language Models (LLMs) with iterative planning, persistent state repositories, heterogeneous tools, and multi-agent coordination frameworks has driven the transition toward autonomous Agentic Artificial Intelligence (AI). While unlocking broad capabilities, agentic architectures dismantle traditional security perimeters by granting probabilistic models direct effectuation authority over digital and physical environments, collapsing the boundary between untrusted data and executable control logic. This paper presents a systematic survey of the expanding attack surface, threat models, defensive architectures, and empirical benchmarks governing Agentic AI. We formalize an end-to-end reference architecture across the perception-cognition-action-reflection lifecycle, dissecting the expanded Trusted Computing Base and fragile trust boundaries across single-agent and multi-agent topologies. Expanding upon foundational systematizations, we establish an analytical taxonomy spanning prompt injection, RAG and embedding poisoning, memory corruption, tool shadowing, Remote Code Execution, Model Context Protocol (MCP) vulnerabilities, and Byzantine consensus subversion. Furthermore, we critically analyze defense-in-depth mechanisms, contrasting empirical guardrails with formal policy verification, capability-based sandboxing, and runtime invariant enforcement. Finally, we provide a unified comparative matrix of contemporary security benchmarks, examine emerging regulatory governance, and articulate open research challenges for engineering secure, verifiable autonomous systems.
\end{abstract}
